# CRA Direct GitHub Pages Site

Static landing page for CRA Direct and the public Cyber Resilience Act tooling ecosystem.

## Purpose

This site converts GitHub visitors into demo users and pilot conversations.

It links to:

- CRA SBOM Validator
- Stateless Scanner Demo
- CRA API Examples
- CRA Direct Docs

## Local Preview

Open `index.html` directly in a browser.

## Publishing

Create the GitHub repository:

```text
Cyber-Resilience-Act.github.io
```

Then push this repo to:

```text
https://github.com/Cyber-Resilience-Act/Cyber-Resilience-Act.github.io.git
```

GitHub Pages will publish the site at:

```text
https://Cyber-Resilience-Act.github.io
```
